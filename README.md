# KurumsalWeb

Bu klasör `Kurumsal Web` adında basit bir web sitesi projesi için hazırlandı.

## Başlangıç

1. `index.html` dosyasını tarayıcıda aç.
2. `styles.css` ile tasarımı düzenle.
3. `script.js` ile küçük etkileşimler ekle.

## Git ile ilerleme

Her adımı küçük değişiklikler halinde commitlemek için:

```bash
git init
git add .
git commit -m "Proje iskeleti oluşturuldu"
git add .
git commit -m "İlk tasarım eklendi"
```

## Sonraki adımlar

- İçeriği kendi şirket ve hizmet bilgilerinle güncelle.
- Yeni sayfalar veya bölüm ekle.
- Responsive düzeni zenginleştir.
